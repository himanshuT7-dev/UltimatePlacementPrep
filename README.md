## ✨ Features

- **🎓 5 Comprehensive Tracks**: Java (OOPs & Core), SQL & Databases, JavaScript, React.js, and Communication & HR.
- **🎙️ AI Voice Agent**: Interactive Mock Interviews powered by Gemini API, complete with speech synthesis and voice feedback.
- **🔄 Spaced Repetition (SM-2)**: Smart review dashboard ensures you never forget what you've learned.
- **🖥️ In-Browser IDE**: Practice SQL and JS right in your browser with the SQLSandbox and JSPlayground.
- **📱 Fully Responsive**: Seamless experience on desktop, tablet, and mobile devices.
- **🔥 Beautiful UI**: Custom Liquid Metal Dark Titanium design system with rich micro-animations.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/UltimatePlacementPrep.git
cd UltimatePlacementPrep
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Variables
Create a `.env` file in the root directory and add your Gemini API Key for the AI Mock Interview feature to work:
```env
VITE_GEMINI_API_KEY=your_api_key_here
```

### 4. Run the Development Server
```bash
npm run dev
```

## 🌐 Deployment (Vercel)

Deploying to Vercel is extremely easy:
1. Push your code to GitHub.
2. Go to [Vercel](https://vercel.com/) and click **Add New... > Project**.
3. Import your GitHub repository.
4. **Important**: In the *Environment Variables* section, add `VITE_GEMINI_API_KEY` and set its value to your Gemini API key.
5. Click **Deploy**.
